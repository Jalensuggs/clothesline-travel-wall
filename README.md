# 晾着的旅程 · Clothesline Travel Wall

把旅行照片夹在一根会晃动的绳子上。灵感来自 [rope-gallery](https://github.com/thebuggeddev/rope-gallery)，代码是重新写的，做成了旅行照片墙。

```bash
npm install
npm run dev
```

## 功能

| 功能 | 怎么用 |
| --- | --- |
| 故乡 · 广州 | 排在最前面的一段：故乡卡介绍广州，后面依次是小学、初中、高中、本科、硕士，小地图画出成长路线 |
| 拖动绳子浏览 | 鼠标或手指拖动、滚轮、← → 方向键，松手后自动停到最近的一张 |
| 点开卡片 | 单击照片（或按 Enter）：照片从夹子上摘下飞到中央，夹子留在绳子上 |
| 明信片背面 | 点照片或按 F 翻面：邮票、邮戳、坐标，游记可以直接编辑，自动保存 |
| 导出明信片 | 灯箱里点「导出明信片」，生成 2400×1600 的 PNG |
| 多段旅程 | 顶部切换，旧卡片掉落、新卡片一张张夹上去；每段旅程开头是一张登机牌 |
| 标签筛选 | 城市 / 山 / 湖……按标签重新挂一遍 |
| 路线小地图 | 按经纬度画出航线，小飞机跟着绳子的位置移动，点地图上的数字可以跳转 |
| 回放旅程 | 空格键，自动一站一站往下滑 |
| 夜晚模式 | N 键，绳子变成串灯，暖光照在照片上 |
| 起风 | W 键，照片随阵风摆动、翻转 |
| 添加照片 | 拖进窗口或点「添加照片」：读取 EXIF 拍摄时间和 GPS，拍立得式显影；数据只存在浏览器的 IndexedDB 里 |
| 音效 | M 键，WebAudio 现场合成，不需要音频文件 |

## 照片

`public/photos/` 里的 30 张照片来自 Wikimedia Commons，作者和授权见 [CREDITS.md](CREDITS.md)，页面里照片背面也标注了署名。

换成自己的照片：替换 `public/photos/` 里的同名文件，或者在 `src/data/trips.js` 里改 `photo` 路径；用自己的照片时可以删掉对应的 `credit` 字段。图片加载失败会自动回退到程序画的插画。也可以直接在页面里拖入照片，放在「我的旅行」里。

## 目录

```
src/
├── main.js            入口：状态、界面、输入、主循环
├── data/trips.js      旅程数据
├── art/
│   ├── scenes.js      16 个目的地的程序化插画
│   └── cardArt.js     拍立得、登机牌、邮票、邮戳、导出明信片
├── scene/
│   ├── stage.js       渲染器、相机、灯光、像素↔世界坐标布局
│   ├── rope.js        绳子（弧线 + 一维波动方程）
│   ├── cards.js       卡片槽位、无限循环、单摆物理、换场动画
│   ├── bulbs.js       夜晚串灯
│   └── textures.js    贴图缓存、异步加载照片、显影动画
├── ui/
│   ├── lightbox.js    灯箱（FLIP 动画、翻面、编辑、导出）
│   ├── minimap.js     路线小地图
│   └── uploader.js    拖入照片、读 EXIF、压缩
└── lib/               工具函数、IndexedDB、音效
```
